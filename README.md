# Noor Fatima - Personal Portfolio

Task 1: Personal Portfolio Website for Full Stack Development Internship.

## Features
- Separate Home, About, Projects and Contact pages
- Responsive design for mobile, tablet and desktop
- Project showcase
- Contact form with JavaScript validation
- Professional UI
- GitHub Pages deployment ready

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deployment
Upload the complete folder to a GitHub repository, then enable GitHub Pages from Settings > Pages.
